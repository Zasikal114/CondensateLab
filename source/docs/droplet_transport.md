# 交互式液滴转运模型

此模块用于快速探索多液滴在两道膜之间的运动、聚并和孔道形变。它是新增的粗粒化模型，不是所提供 Cahn–Hilliard 方程的等价求解或实验校准模型。旧版浓度场与区室模型入口及实现已从当前软件移除。

## 状态和动力学

每个液滴记录位置、物料量、半径、所在区室和过孔进度。胞外可溶物料通过表面控制的生长项转入液滴，始终保持总物料守恒。

自由运动采用过阻尼随机运动：随机增量方差为 2 D Δt / r，并叠加膜附近的捕获项及胞质向核转运项。膜面阻挡自由位移，液滴靠近入口后进入门控转运状态。过孔进度满足 dq/dt = P(1+0.4 A) / [r (1+(r/a)^2)]，分别使用细胞膜和核膜的 P。这个经验关系表达孔径变小、液滴变大时过孔阻力增加，不是由团队原 PDE 严格推导的速率律。

接触液滴按物料加权合并，合并前后的物料量相同。过孔阶段以两侧液滴瓣及细颈表示形变；这些形状由实际的过孔进度和物料量生成。核内使用受限随机运动。

## 动画与曲线

每个时刻把液滴物料分配到归一化的平滑密度核，并对孔道外的膜带施加掩膜。每个核归一化为对应液滴的物料量，可溶池另行计入胞外。图像颜色采用 phi = -1.1 + 2.5 rho 的显示变换。曲线由同一密度网格在各区室和膜带上求和得到；四条曲线之和为 1。

坐标与时间使用模型单位，不输出校准过的 nm、μm、秒或入核概率。动画记录 72 个实际计算时刻，不使用用户参考视频、录制画面或预设粒子轨迹。

## 边界与局限

胞质和核内转运的有效参数需要实验标定。本模型不解析流体速度、FG 网络结构、分子结合细节或完整界面自由能。它适合交互式演示和参数趋势探索；不能直接替代原始场模型或用于定量预测实验。
